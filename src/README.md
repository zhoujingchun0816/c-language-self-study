# C语言小蓝书

一个无需安装、无需联网的中文 C11 语法速查网页。

## 打开方式

直接双击 `index.html`，或将它拖入浏览器。页面通过普通脚本加载本地数据，使用 `file://` 协议即可完整工作，不需要启动服务器。

## Windows 免安装版

Windows 用户也可以从 Releases 下载 `C-SelfStudy-v<版本>-portable.exe`（Windows 免安装版），无需安装，双击即可在 Edge 或 Chrome 的独立应用窗口中使用。程序会把内嵌页面与独立浏览器配置保存到 `%LOCALAPPDATA%\C语言自学本地网站\`；删除该目录即可彻底清理。

## Android 版

Android 用户可以从 Releases 下载 `C-SelfStudy-v<版本>-android.apk`（Android 安装包）侧载到手机；应用名称显示为「C语言小蓝书」。首次安装时需要为文件管理器或浏览器开启“允许安装未知应用”。页面数据保存在 App 私有目录中，卸载 App 时会一并清理。APK 使用 debug 证书签名，仅供个人使用，不能上架应用商店。

正式版本见仓库 [Releases](https://github.com/zhoujingchun0816/c-language-self-study/releases) 页；单文件网页附件名为 `c-syntax-lookup-v<版本>.html`。

## 三套主题切换

页面默认使用蓝色主题（页面底色 `#5A8CD7`），不跟随系统深浅色设置。页头的三档滑块可随时切换「浅色 / 蓝色 / 深色」：浅色主题使用纯白页面底色，深色主题只使用黑色和灰色；选择会保存在本机浏览器中，下次打开时自动恢复。

## 零基础怎么用这个网页

建议先在分类中选择「入门基础」，认识程序结构、变量、输入输出和基本调试方法；再学习「基础语法」，逐步浏览流程控制、函数、数组、指针等词条。每学完一个词条，就做详情页末尾的练习：先看题目和提示，自己写代码并在本地运行，遇到问题再展开参考答案。配置 DeepSeek API Key 后，还可以把自己的代码粘到练习下方，让 DeepSeek 只检查问题并给建议。

## 按学习顺序学

侧栏默认按 C 语言学习过程排列词条，每条上方的步骤徽标会标明当前处于「第几步」。展开侧栏的「跳到学习步骤」，可以直接跳到变量、输入输出、流程控制、函数、指针等阶段；输入搜索词后则仍按搜索相关度排列。

在分类中选择「入门基础」，详情面板最上方会显示可折叠的 C 语言学习流程图；也可以直接打开「C 语言学习路线图」词条。流程图中的方框都可以点击，并会打开对应知识词条。零基础建议按这个顺序使用：**路线图 → 入门基础 15 条 → 每一步词条下面的练习 → 让 DeepSeek 批改**。

侧栏有常驻的「在线刷题」窗口，可直接跳转 LeetCode 中文站与洛谷；建议先学完基础语法并做完词典里的练习，再开始刷题。

网课、工具官网和下载页都是外部链接，点击后会在新标签页打开；页面的查询、词条和练习数据仍保存在本地，无需联网即可使用。

## 练习题怎么跑

网页出于离线和体积考虑没有内嵌 C 编译器。可以复制参考答案，也可以从题目给出的框架开始自己写，然后用本地 gcc、Dev-C++ 或可信的在线 C 编译器编译运行。使用 gcc 时，可在代码文件所在目录执行：

练习代码输入框支持直接按 Enter 换行，并会按练习自动保留当前会话中的草稿，切走再回来也不会丢失。

保存 DeepSeek API Key 后，每道练习题底部还可以让 AI 围绕同一知识点继续出题；可以选择生成 1、3 或 5 道，并填写想重点练习的方向。生成结果会以纯文本显示在题卡下方，可直接复制到本地，用下面的 gcc 命令编译验证。

```text
gcc -std=c11 -Wall -Wextra 练习.c -o 练习
```

再运行生成的程序，并把输出与网页里的「运行后应该看到」逐字对照。项目维护者可运行 `node tools/verify-exercises.mjs`，逐题检查参考答案和起始代码是否零告警编译，以及实际输出是否与预期一致。练习不得使用 `tmpfile()`，改用当前目录临时文件 + `remove` 收尾。

## DeepSeek 批改

「让 DeepSeek 检查我的代码」只会在浏览器已经保存 API Key 后显示。把自己写的代码粘进去并点击按钮，页面会连同题目和要求一起发送；批改模式只指出编译、逻辑、边界或风格问题并给改进建议，不会重写学生代码，也不会直接提供完整答案。API Key 仍只保存在当前浏览器的 localStorage 中。

电脑端的对话面板可拖动四边或四角调整大小，也可用标题栏按钮（或双击标题栏）一键放大/还原，调整后的非放大尺寸会被浏览器记住；手机端保持整宽底部面板，不提供缩放操作。

## 查询与快捷键

- 在顶部输入关键字即可实时过滤；查询不区分英文大小写。搜索先匹配名称、别名、**中文关键词**、头文件、作用、用法、摘要、语法和注意事项，仅当这些字段均无结果时才回退搜索示例代码，并显示“在示例代码中匹配”提示。
- 分类、头文件与关键字同时生效，三者是“与”关系。头文件下拉仅列出当前数据实际使用的标准头，按字母排序；选择 `stdio.h` 可只看需要该头文件的条目。
- `/` 或 `Ctrl+K`：聚焦搜索框。
- `↑` / `↓`：移动当前选择；`Enter`：打开所选详情；`Esc`：清空查询、分类和头文件筛选。
- 详情标题下会列出所需的 `#include <...>`；头文件标注、语法与示例代码均可一键复制。

## 用中文搜（关键词）

除了名称和正文，每条词条还带一组**中文关键词**（例如 `malloc` 带「内存」「动态分配」「堆」「申请内存」）。所以可以直接用中文搜：

| 你搜 | 能捞到 |
|---|---|
| 内存 | malloc、calloc、realloc、free、动态数组、内存泄漏、悬空指针… |
| 字符串 | strlen、strcmp、strcpy、strstr、strtok、memcpy… |
| 文件 | fopen、fclose、fread、fwrite、fgets、fseek… |
| 输入 / 输出 | scanf 系列 / printf 系列、puts、putchar… |
| 时间 | time、localtime、strftime、struct tm… |
| 数学 | sqrt、pow、log、sin、floor、round… |
| 排序 / 查找 | qsort / bsearch、strstr |
| 指针 · 数组 · 结构体 | 指针声明、取地址、数组越界、成员访问… |

关键词命中排在“正文里碰巧出现”的结果之前；详情页里每个关键词都是可点击的标签，点一下就等于搜这个词。

关键词集中定义在 `data/keyword-concepts.js`（“中文概念 → 词条族”的映射，外加逐条覆盖），生成产物是 `data/keywords.generated.js`。改完概念表后运行：

```text
node tools/build-keywords.mjs
```

它会重新生成关键词，并顺手跑一遍「中文查询矩阵」自检（内存/字符串/文件/时间/数学/指针/数组… 每个词至少能搜到多少条）。

## 接入 DeepSeek（可选，只用于问答）

页面右下角「问 DeepSeek」→ 填入你自己的 DeepSeek API Key 就能用，**其它都不用配**。

电脑端可拖动面板四边/四角调整尺寸，也可一键放大，非放大尺寸会自动记住；手机端保持整宽底部面板。

- 预配置：接口 `https://api.deepseek.com/chat/completions`、模型 **`deepseek-flash`**（官方 DeepSeek-V4.1-Flash 的模型 id，**固定不可改**，面板里只作展示）、推理强度 `medium`（可选 low/medium/high）。若服务端不接受 `reasoning_effort`，会自动去掉该参数重试一次并告知。
- **模型为什么只有一个**：官方 API 只接受 `deepseek-flash` / `deepseek-v4-pro` 这类 id，写成 `deepseek-v41-flash` 会被 400 拒绝。为避免选错，面板不再提供模型下拉；如果浏览器里残留了旧版本保存过的模型名，页面**会在启动时自动丢弃它并回落到 `deepseek-flash`**，请求里不会再出现无效 id。若仍看到「服务端不接受这个模型名」，说明你打开的是旧文件，请换成最新的单文件版。
- **会花钱**：面板里所有模型都是 **API 调用**，按 token 从你的账户余额扣费（官方计费见 [Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing)）。网页版 `chat.deepseek.com` 的免费额度与这里**无关**，它用的是账号登录、不是 API Key。本页面在**没有填 Key 时不会发出任何请求**，离线查询永远免费。
- 官方取值是 `low/high/max`；`medium` 在官方映射表里等价于 `high`（思考模式默认就是 high）。思考模式下 `temperature` 会被忽略（不报错、也不生效）。
- 没有填 Key 时不会发任何请求；**离线查询完全不受影响**（聊天模块单独 try/catch，出错也不影响词典）。
- **Key 只保存在本机浏览器的 localStorage**（键名 `csyntax.deepseek.apiKey`），不上传到任何地方、也不写进任何文件；输入框是密码框，保存后只显示掩码，面板里可随时「清除 Key」。
- 面板里有一行「**没有api？**」，下面是跳转 DeepSeek 平台获取 API Key 的按钮。
- 这个对话以 **C 语言问题**为主，也允许问好、道谢或闲聊一两句；写小说/文案、代写整篇作业或论文、医疗/法律/投资等其它专业领域的深入咨询仍会被礼貌拒绝。你正在看的词条会自动作为上下文带进去，可以直接问“这个怎么用”。

## 添加词条

`data/c-syntax-data.js` 只提供注册器与 `C_SYNTAX_PROGRAM` 示例拼装函数。请在 `data/entries/` 下对应主题文件的 `C_SYNTAX_ADD_ENTRIES([...])` 数组中追加对象，不要改变 `index.html` 中的数据脚本加载顺序。

每条词条必须包含唯一的英文小写短横线 `id`，以及 `name`、`aliases`、`category`、`summary`、`behavior`、`syntax`、`headers`、`usage`、`example`、`notes`、`related`。其中：

- `headers` 是所需 C11 标准头文件名数组，不带尖括号和 `#include`；纯语法可使用空数组。
- `behavior` 是详情页的“作用”说明，必须是至少 50 个字符且包含中文的全局唯一字符串。它面向零基础读者，按“做什么 → 怎样处理参数或执行过程 → 不同输入分别产生什么结果或返回什么”的顺序写；函数类词条必须明确写出“返回”，建议不少于 80 个字符。不要复述摘要，也不要使用“适合在”“相关场景中使用”“本条语法用于”“前置条件”等空泛模板句。
- `usage` 是至少 20 个字符且包含中文的使用说明，应说明适用场景与搭配方式。
- `notes` 至少 3 条，每条至少 10 个字符；保留易错点、返回值或边界检查以及可移植性信息。
- `example` 必须是含 `int main(void)` 与 `return 0;` 的完整 C 程序。其全部 `#include <...>` 必须与 `headers` 集合完全一致，不多也不少，并通过 C11 零告警语法检查。
- `related` 中的 ID 必须已经存在。

16 个分类名称是固定值。新增分类前应同步更新 `app.js` 与 `tools/verify.mjs` 中的分类清单。

## 运行自检

在本目录打开终端并运行：

```text
node tools/verify.mjs
```

脚本只使用 Node 标准库，会从 `index.html` 解析并按页面顺序加载数据脚本，检查文件与 JavaScript 语法、词条结构、92 条下限、16 类覆盖、相关链接、离线约束、`headers` 白名单及其与示例 include 的一致性、`behavior`/`usage`/`notes` 完整度、头文件下拉数据源、三类筛选的“与”关系、分层搜索和示例回退。`behavior` 还会检查长度、中文、函数返回值说明、全局唯一性和反模板句。随后会尝试用 `gcc -std=c11 -Wall -Wextra -fsyntax-only` 逐条零告警编译示例。

子进程输出通过项目内 `tools/.tmp/` 临时文件的文件描述符捕获，不使用管道；运行结束会清理临时目录。编译器查找顺序为环境变量 `CC`、`gcc`、`cc`、预设 MinGW 路径；全部候选均不可用时会逐条显示候选命令的失败原因，并明确显示 `SKIP` 和跳过数量。

## 版本与发布

单文件产物按 `c语言自学本地网站v<版本>.html` 命名。每次修改后，在 `c-syntax-lookup-standalone` 目录依次运行：

```text
node bump-version.mjs
node build-standalone.mjs
node sync-github-repo.mjs
```

第一步把版本号最后一段加一（也可用 `node bump-version.mjs --to 1.35` 指定版本），第二步构建当前版本并保留历史产物，第三步刷新待上传的 `github-repo/` 目录。
